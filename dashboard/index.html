    How this fits into context drift detection
    01 / Extract

    Read the sources

    Parsers extract structural facts. Models propose business meaning with confidence and provenance.

    02 / Connect

    Build shared context

    Named graphs connect services, tasks, policies, and contracts. This workspace explores those facts.

    03 / Compare

    Identify stale context

    The Python drift module compares supplied graph versions and agent snapshots using controlled examples.

    04 / Recommend

    Return a correction

    Recommendations describe continue, refresh, re-brief, re-plan, or rollback. Agent actions are not executed.

    This is a research prototype. The graph explorer is implemented; live agent monitoring and automatic remediation are not integrated.

    What am I looking at? A quick guide

    Follow the arrows

    Nodes are extracted services, entities, tasks, or document concepts. Arrows read from subject to object: a task invokes a service, or a policy constrains a service. Drag to pan, use the zoom controls, and select Fit graph to return to the full view.

    Interpret confidence carefully

    Deterministic facts come from a parser or fixed rule. Probabilistic facts come from model-assisted extraction. Confidence describes the extraction process; it is not a calibrated guarantee of business truth.

    Understand filtered results

    Only relationships with two visible endpoints appear. A source filter also restricts arrows to that source. Cross-source bridges live in a separate graph. Missing evidence is shown as unavailable.
